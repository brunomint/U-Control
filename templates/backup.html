Guarde tudo num arquivo, ou leve para outro computador com o U-Control

Fazer backup

Um arquivo .zip com as músicas e cifras, as ordens de culto, os usuários, as configurações, as fotos, os slides, os vídeos e os áudios deste U-Control.

 

Baixar backup

Montando o arquivo… com muitas fotos pode levar um minuto.

Restaurar backup

Use para trazer os dados de outro U-Control (do Raspberry Pi para o Windows, de um computador antigo…) ou voltar a um backup guardado.

Substitui tudo o que está neste U-Control pelo que está no arquivo, inclusive os usuários: depois, entre com um usuário do backup. O que existe agora fica guardado numa cópia automática, na pasta de dados (instance/backups).

Backup grande (muitas fotos e vídeos)? Restaure pela rede da igreja, com o endereço http://<ip>:8585 ou no próprio computador: pelo endereço da internet, arquivos acima de 100 MB são barrados no caminho.
