Como configurar

Stream Deck (Bitfocus Companion)
  1. No Companion, adicione a conexão Generic HTTP Requests.
  2. Em cada botão, ação GET com o endereço do comando (copie daqui).
  3. Com o Companion em outro computador, use o endereço de rede: {{ base }}.
QuickDeck ou outro programa

Qualquer programa que faça uma requisição GET ou POST para o endereço serve. A chave também pode ir no cabeçalho X-UControl-Chave em vez de no endereço. A resposta é um JSON com "ok": true ou o motivo do erro.
