# Quadro Kanban - Sistema U-Control

## Visão Geral
Este quadro Kanban foi criado para gerenciar o desenvolvimento e manutenção do sistema de gerenciamento de músicas U-Control. O sistema é construído em Flask (Python) com interface web responsiva.
